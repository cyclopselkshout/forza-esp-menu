## 🧩 About

**Forza Horizon overlay Menu** is a curated list of Forza Horizon open-source tools:

- **Overlays** — on-screen helpers, layout notes, HUD customization, overlay view
- **Quality-of-Life Helpers** — car catalog, livery manager, overlay notes
- **Research Notes** — race layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Driving Helpers
- Racing Line — visual guidance for practice
- Speedometer HUD — real-time speed and gear display
- Mini-map overlay — enhanced map with points of interest
- Replay Notes — record and review race runs

### 🎨 Catalog & Cosmetics
- Car Catalog — browse cars, colors, upgrades
- Livery Manager — organize custom designs
- Photo Mode Notes — tips for in-game photography

### 🏋️ Practice Layout
- Drift Score Tracker — monitor drift chains
- Skill Score Notes — track skill combos
- Route Planner — plan custom races
